JS Question 1 · 10 marks

How JavaScript runs in a page

A JS exam answer is always two files: index.html (what the user sees) and script.js (what happens when they click). The HTML has three ingredients: inputs to type into, a button to click, and an empty output box (a div or label) that JS writes into.

@@code html index.html — the skeleton for every JS question My App
Waiting for input...
@@end
Why the script goes last

The browser reads HTML top to bottom. If <script> were in the <head>, it would run before the button exists, so document.getElementById("addBtn") would return null and you’d get “Cannot read properties of null”.

No <form> tag in the JS question

A <button> inside a <form> submits the form and reloads the page. Every variable resets to 0, so the running total disappears. Keep inputs and button loose in the <body>.

Testing without HTML: the console

The Basic JS lecture practises in the browser console (right-click → Inspect → Console). prompt() reads input and console.log() prints. In the exam you’ll use HTML inputs instead, but console.log() is still your best debugging tool. Print a variable to see what it really holds.

@@code js console practice let userName = prompt("What is your name?"); // always returns a STRING console.log("Hello, " + userName); let age = Number(prompt("Enter your age:")); // convert to number console.log("You will be " + (age + 1) + " next year."); @@end

Variables, types and reading input

let and const

@@code js const GOAL = 2000; // const: never changes (goal, limits, prices) let total = 0; // let: changes over time (totals, counts) let isDone = false; // boolean let subject = "Math"; // string let subjects = []; // array (a list) @@end

Use const for numbers the question fixes (“daily goal of 2000”, “weekly goal of 20 hours”). Use let for anything you add to. Avoid var; it works but has confusing scoping rules.

The #1 bug: input is always text

.value from an input, and prompt(), always give a string, even for type="number". With strings, + joins text instead of adding.

Try it · string vs number
@@code js converting let raw = document.getElementById("numInput").value; // "5" (string) let a = Number(raw); // 5 — handles decimals: Number("2.5") = 2.5 let b = parseInt(raw); // 5 — whole numbers only: parseInt("2.9") = 2 let c = parseFloat(raw); // 5 — decimals: parseFloat("2.5") = 2.5 Number("") // 0 (empty box becomes 0!) Number("abc") // NaN (Not a Number) parseInt("") // NaN if (isNaN(a)) { // reject bad input return; // (inside a function: stop here) } @@end
Which one to use

Use Number() when hours or readings can be decimals (study hours, SpO2). Use parseInt() for counts and guesses. Both are accepted in the exam; just don’t forget to convert.

if / else if / else for ranges

Nearly every JS question asks for a feedback message “based on ranges”. Write the chain in order and let each else if assume the earlier checks failed:

@@code js feedback by range (Spring 2026 Set A) let msg = ""; if (total <= 5) { msg = "Start studying regularly!"; } else if (total <= 12) { // we already know total > 5 msg = "Good progress!"; } else if (total <= 19) { msg = "Almost ready!"; } else { // 20 or more msg = "Weekly goal reached!"; } // Special rule that OVERRIDES the range message — put it AFTER the chain if (sessions > 7 && total < 20) { msg = "Increase your study time!"; } @@end
Gaps in the ranges

Questions write ranges like “0–5, 6–12, 13–19”. Hours can be decimals (5.5 falls in no range!). Using <= 5, <= 12, <= 19 covers every value with no gaps.

Loops

@@code js // for: when you know how many times for (let i = 0; i < subjects.length; i++) { console.log(subjects[i]); } // for...of: walk through every item of an array (simplest) for (let s of subjects) { console.log(s); } // while: repeat until something changes let count = 3; while (count > 0) { console.log("Countdown: " + count); count--; } @@end

In the exam you rarely need a loop for the main logic. The button click is the loop: each click runs your function once more. You might loop to build a list for display or to sum an array.

Functions

@@code js three ways to write a function // 1. Function declaration function average(total, count) { return total / count; } // 2. Anonymous function given to an event listener document.getElementById("addBtn").addEventListener("click", function () { // runs on every click }); // 3. Arrow function (short form, used with map/filter/reduce) const double = n => n * 2; const add = (a, b) => a + b; @@end

Questions often say “Inside a function: …”. Either a named function called by the listener, or the anonymous listener function itself, satisfies that.

@@code js named function + listener function handleClick() { // all the logic } document.getElementById("addBtn").addEventListener("click", handleClick); // no () here! @@end
Pass the function, don’t call it

addEventListener("click", handleClick()) runs handleClick once immediately and gives the listener its return value (undefined). Write handleClick without parentheses.

Scope: why counters must be global

A variable declared inside a function is created fresh every time the function runs. To remember something between clicks (attempt count, running total, list of readings), declare it outside, at the top of script.js.

Try it · global vs local counter
global count = 0 · local count = 0
The local counter is declared inside the click function, so it restarts at 0 and only ever reaches 1.
@@code js let globalCount = 0; // lives across clicks btn.addEventListener("click", function () { let localCount = 0; // re-created on every click globalCount++; localCount++; // globalCount: 1, 2, 3, 4 ... localCount: 1, 1, 1, 1 ... }); @@end
JS

Arrays

Newer papers ask you to “store each subject name” or “keep track of every reading”. That means an array declared globally and filled with push().

@@code js add, remove, read let fruits = ["Apple", "Banana"]; fruits.push("Mango"); // add to END → ["Apple","Banana","Mango"] fruits.unshift("Kiwi"); // add to START → ["Kiwi","Apple","Banana","Mango"] fruits.pop(); // remove from END → ["Kiwi","Apple","Banana"] fruits.shift(); // remove from START → ["Apple","Banana"] fruits.splice(1, 1, "Orange"); // at index 1, delete 1, insert "Orange" → ["Apple","Orange"] fruits.length // 2 fruits[0] // "Apple" (first) fruits[fruits.length - 1] // "Orange" (last) fruits.includes("Apple") // true fruits.indexOf("Orange") // 1 fruits.join(", ") // "Apple, Orange" ← great for display @@end

map, filter, reduce

These walk the array for you and return something new without changing the original.

@@code js let nums = [10, 20, 30]; let doubled = nums.map(n => n * 2); // [20, 40, 60] transform each let big = nums.filter(n => n > 15); // [20, 30] keep the ones that pass let sum = nums.reduce((acc, n) => acc + n, 0);// 60 boil down to one value let avg = sum / nums.length; // 20 Math.max(...nums) // 30 (... spreads the array into separate arguments) Math.min(...nums) // 10 @@end

The callback can also take the index and the whole array, which lets you compare with neighbours (from the Basic JS lecture):

@@code js hotter than the previous day let temps = [20, 22, 21, 25]; let hotter = temps.filter((t, i, arr) => { if (i === 0) return false; // first day has no previous return t > arr[i - 1]; }); // [22, 25] @@end

@@code js let hr = [80, 78, 130]; // with a loop let sum = 0; for (let x of hr) sum += x; let avg = sum / hr.length; // 96 // with reduce let avg2 = hr.reduce((a, b) => a + b, 0) / hr.length; // 96 @@end

Regex .test(): does the string contain …?

The password question needs “is there an uppercase letter / number / special character?”. A regex in slashes, then .test(str), returns true or false:

@@code js /[A-Z]/.test(pw) // any uppercase letter? /[a-z]/.test(pw) // any lowercase letter? /[0-9]/.test(pw) // any digit? /[!@#$%^&*]/.test(pw) // any of these special characters? @@end

Math

@@code js Math.floor(3.9) // 3 round DOWN Math.ceil(3.1) // 4 round UP Math.round(3.5) // 4 nearest Math.abs(78 - 80) // 2 distance, always positive Math.max(4, 9, 2) // 9 (90.6666).toFixed(2) // "90.67" (a string, 2 decimals) // Random whole number between min and max (both included) let secret = Math.floor(Math.random() * (max - min + 1)) + min; // 500..5000 → Math.floor(Math.random() * 4501) + 500 @@end
How the random formula works

Math.random() gives 0 ≤ r < 1. Multiply by the number of possible values (max − min + 1), floor it to get 0…(count−1), then shift up by min.

Rounding for display

toFixed(2) always shows 2 decimals (“96.00”). To drop pointless zeros, use Math.round(x * 100) / 100: 96 stays 96, 90.6666 becomes 90.67.

The DOM: reading and writing the page

The DOM is the browser’s live model of your HTML. JS finds elements, reads what the user typed, and writes results back.

@@code js // FIND let input = document.getElementById("numInput"); // by id (main way) let box = document.querySelector("#output"); // CSS selector: #id, .class, tag let all = document.querySelectorAll(".item"); // every match (a list) // READ let text = input.value; // what the user typed (string) // WRITE box.innerText = "Too high!"; // plain text box.innerHTML = "Total: 5
Avg: 2"; // text + HTML tags like
, box.style.color = "green"; // change CSS // CONTROL input.value = ""; // clear the box for the next entry input.disabled = true; // lock the input (game over) input.focus(); // put the cursor back // EVENTS document.getElementById("addBtn").addEventListener("click", function () { // runs every time the button is clicked }); @@end
innerText

Shows exactly the characters you give it. "<br>" appears literally.

innerHTML

Parses tags. Use it when your output has line breaks (<br>) or bold text.

onclick in HTML: the other way

You may also see <button onclick="check()"> with function check(){…} in script.js. It works and is acceptable; the lecture prefers addEventListener because it keeps HTML and JS separate.

JS · the template

The 4-step exam workflow

Every JS question since 2024 fits this template. Memorise the shape; only the logic in step 4 changes.

Step 1HTMLinputs with id, button with id, output div, script at bottom
Step 2Globalsconst GOAL; let total = 0, count = 0, list = []
Step 3Listenerread .value → convert → validate → update globals
Step 4Logic + showif-else feedback → innerHTML → clear input
@@code js script.js — fill-in-the-blanks template // STEP 2: global state (survives between clicks) const GOAL = 2000; let total = 0; let count = 0; let items = []; // STEP 3: listen for the click document.getElementById("addBtn").addEventListener("click", function () { let inputBox = document.getElementById("numInput"); let value = Number(inputBox.value); if (isNaN(value) || inputBox.value === "") return; // ignore bad input total += value; // update state count++; items.push(value); // STEP 4: decide the message let msg = ""; if (total <= 800) msg = "..."; else if (total <= 1600) msg = "..."; else msg = "..."; if (count > 10 && total < GOAL) msg = "..."; // override rule last // show it document.getElementById("output").innerHTML = `Total: ${total}
Entries: ${count}
Feedback: ${msg}`; inputBox.value = ""; // clear for next entry }); @@end
Checklist before you hand in
  • Every id in JS matches the HTML exactly (case-sensitive).
  • Counters and totals are declared outside the function.
  • Input converted with Number() or parseInt().
  • The “override” rule (too many attempts, etc.) comes after the range chain.
  • Output shows everything the question lists (total, average, list, feedback).
