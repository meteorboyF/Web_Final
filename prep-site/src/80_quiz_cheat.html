Words → SQL
  • “for each / per X” → GROUP BY X
  • “number of” → COUNT(*) · “total” → SUM() · “average” → AVG()
  • “only groups with …” → HAVING
  • “most / largest first” → ORDER BY … DESC
  • “top 3” → LIMIT 3
  • “contains X” → LIKE '%X%' · “between a and b (inclusive)” → BETWEEN
  • “only if the result …” → extra AND on the new value
  • “label A or B” → CASE WHEN … THEN … ELSE … END
  • “above its own group’s average” → correlated subquery
Before handing in
  • Ran the first sample row through by hand?
  • Every UPDATE has a WHERE?
  • Text in 'quotes' inside SQL?
  • Aggregates have an AS alias that matches $row["…"]?
  • Parts run in the order given?
  • CREATE / INSERT written in the txt file?
  • JS ids and PHP names match the HTML exactly?
