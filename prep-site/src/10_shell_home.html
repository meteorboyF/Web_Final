Everything you need for the web final

Every final since Fall 2024 uses the same three-question layout. This guide teaches each JS, PHP and MySQL idea those questions use, then works through all six past papers with code, traces and live demos.

Rules from the course walkthrough

JS Question

Do not use a <form> tag. A form reloads the page on submit and wipes your JS variables.

Find elements with id (or class): document.getElementById("x").

PHP Question

Use <form action="file.php" method="post">.

PHP finds inputs by their name attribute: $_POST["x"].

SQL rule

Three kinds of query do not need to be in PHP: CREATE DATABASE, CREATE TABLE and INSERT. Write them wherever is easiest (ideally a .txt file, or run them in phpMyAdmin). SELECT and UPDATE queries go inside PHP code.

The habit that wins marks

Every past paper had at least one sample row that only works if you read the formula carefully (pizza cost per slice, venue waste per person, password length beyond the minimum, “average” that was really a sum). Before you write code, run the first sample row through your formula by hand.

XAMPP and how to run your code

JavaScript runs inside the browser, so double-clicking index.html is enough. PHP is different: it runs on a server. The browser asks the server for a .php file, the server runs the PHP, and sends back only the HTML it printed. XAMPP gives you that server (Apache) and a database (MySQL / MariaDB) on your own machine.

BrowserRequestlocalhost/q2/index.html → you submit the form
ApacheRuns PHPq2/process.php reads $_POST and calculates
MySQLDataPHP sends SQL with $conn->query()
BrowserResponseOnly the echoed HTML comes back

Steps (from the PHP session’s howTo)

  1. Open the XAMPP Control Panel and Start both Apache and MySQL.
  2. Go to C:\xampp\htdocs (Mac: /Applications/XAMPP/xamppfiles/htdocs). Create one folder per question, e.g. q1, q2, q3, and open it in VS Code.
  3. Open pages through the server: http://localhost/q2/index.html. Opening a PHP file as file:///… shows the raw PHP source instead of running it.
  4. For the database, open http://localhost/phpmyadmin → SQL tab → paste your CREATE / INSERT queries → Go.
Common setup mistakes
  • MySQL won’t start → another MySQL is already using port 3306. Stop it, or change the port in XAMPP config.
  • Page downloads or shows code → you opened it with file://, not localhost.
  • “Unknown database” → the database name in new mysqli(…) doesn’t match what you created.
  • XAMPP defaults: user root, password "" (empty).
